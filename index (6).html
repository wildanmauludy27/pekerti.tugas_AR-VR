05 · Tutor Generative AI

Ajukan pertanyaan konsep, minta petunjuk debugging, atau tantangan lanjutan.

AI-assisted learning

Konfigurasi tutor

Untuk respons generatif langsung, masukkan API key milik Anda. Kunci hanya disimpan dalam memori halaman, bukan pada file atau local storage.

Belum punya key? Buat API key di Google AI Studio.

Mode demonstrasi aktif; respons contoh tanpa memanggil model eksternal.

Privasi: jangan gunakan API key pada perangkat bersama. Untuk aplikasi publik/produksi, gunakan backend yang mengelola rahasia. Pertanyaan dan kode yang dikirim dalam mode GenAI diproses oleh layanan Google Gemini.
